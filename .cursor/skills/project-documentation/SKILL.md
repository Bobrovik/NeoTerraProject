# Project documentation

1. Read `AGENTS.md` before editing the repository.
2. Read only the files the current task needs.
3. After a logical change, update the matching section of `AGENTS.md`.
4. Do not rewrite the whole file for a small change.
5. Record current facts. Do not record an assumption as a confirmed fact.
6. When architecture changes, update the Architecture section.
7. List modified files with a short purpose when that list is part of the change.
8. Record a decision that should stay in place unless a later task gives a reason to change it.
